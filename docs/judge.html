The 30-second path

Run bu-021 on the final deployment frozen3 (contract commit e425c78): a forged mint of 500 tUSD on Unichain Sepolia with no lock behind it on Base.

  1. The forged mint lands on Unichain Sepolia.

    A Minted event with no matching Locked on Base. A guard on Unichain alone cannot know that.
    Unichain0x4bfe94f2…a84e

  2. One react() on Lasna sees it, seen 3.175 s after the mint was mined.

    The same transaction emits two CallbackRequest logs, one per gate.
    Lasna0xbacbf5a0…9068

  3. Both gates are paused: Base at 2.184 s, Unichain at 8.062 s (observer clock).

    Block timestamps: mint 1794595469, gate B 1794595470, gate U 1794595471. The Base gate is seen before the Lasna transaction, which we attribute to Lasna RPC visibility lag (not measured separately); block timestamps never invert.
    Gate B · Base0x5eacdc82…4303 Gate U · Unichain0x60f4bcba…f3c4

  4. The next copycat reverts GatePaused, and the release on Base reverts too.

    The mint is in Unichain block 67743041, gate U's Paused in 67743043, and the reverted copycat in 67743044. Exposure: 1,000 tUSD (the forged mint plus one copycat that landed before the pause).
    Copycat · reverted0x6006802e…2fb6 Release · reverted0x80ff77c4…9bfb

  5. Open the live status page.

    It reads both gates' state straight from the public testnet RPCs and lists every committed run with its hashes.

Reproduce

Re-check the live runs on-chain (public RPC reads, no keys):

git clone --recurse-submodules https://github.com/edycutjong/ledgerlock.git && cd ledgerlock
pnpm install
pnpm burst:verify     # re-reads the 25 burst rows (20 headline + 5 paired control) from the chains
pnpm bench:summary    # regenerates the latency, false-pause and burst numbers from evidence/frozen3-bench-runs.csv

Re-run the attack bench live on your own deployment (funded testnet keys, about 25 lREACT):

export LEDGERLOCK_ENV=~/.config/<you>/testnet.env   # deployer key + RPC URLs, outside the repo
INSTANCE=mine script/core-deploy.sh
script/bench-all.sh mine                              # 100 legit + 100 attacks, resumable

CI / deterministic replay (Reactive Test Lib, no network):

forge test && FOUNDRY_PROFILE=kit forge test && pnpm test:coverage

What it does not do

Honest limits

  • The first unbacked mint is lost. Ledgerlock limits the loss to the mints that land inside the measured pause window; it does not prevent the first one.
  • Both routes are ours. Route A is our own fixture bridge with a reproduced Nomad-class bug; route B is our own Hyperlane warp route, delivered by our own Mailbox.process because the public relayer did not deliver within 6 minutes.
  • If Lasna stops, the guard is blind, and nothing pages the operator: a latched route stays shut until someone looks at the IncidentLatched and GateUnreachable events.

All nine limits are in the README.
